#  Requerimientos del sistema
## RF
RF-01. El sistema permitirá registrar asistentes al congreso.
RF-02. El sistema permitirá consultar las actividades disponibles.
RF-03. El sistema permitirá registrar un asistente a una actividad.
## RNF
RFN-01. La interfaz deberá ser accesible desde un navegador web.
RFN-02. El sistema deberá manterer la informacion de registro de manera persistente.
